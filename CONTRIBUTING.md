# Как предложить правку

*In short (English): the project language is Russian; Go without cgo;
run `go test ./...` and `go vet ./...`; keep pull requests small; behaviour
changes go through OpenSpec in the server repository; external contributions
are accepted only after signing the CLA (`CLA.md`) via CLA Assistant.*

## Язык и имена

- Язык проекта — русский: комментарии, тексты в журнале и интерфейсе,
  описания PR, артефакты OpenSpec.
- **Имена в коде — латиницей**, общепринятыми словами. Не транслитерировать.
  Словарь узлов и слов для имён — `docs/GLOSSARY.md` и `docs/NAMES.md` в
  репозитории сервера: [PavluninVladimir/sema](https://github.com/PavluninVladimir/sema).
- Сёма — он: «Сёма предложил», «Сёма сам».

## Код

- **Никакого cgo.** Бинарник кросс-компилируется под Linux и macOS; то, что
  есть только на одной системе, проверяется во время работы, а не тегами
  сборки.
- Агент **только читает**: файлов не правит, команд не запускает. Правка,
  которая это меняет, — отдельное решение через OpenSpec, а не PR.
- Новый флаг или переименованный — вместе с файлами службы в `deploy/`:
  `deploy_test.go` сверяет одно с другим.
- Ошибка связи — ошибка, а не пустой ответ. Отсутствие инструмента —
  честная пометка яруса, а не молчание.

## Проверки перед PR

```sh
gofmt -l .
go vet ./...
go test ./... -count=1
make build
```

## Как устроен PR

- Маленький и об одном. Исправление и «заодно улучшил» — разные PR.
- Изменение поведения (протокол с Сёмой, способности, роли, хуки) сначала
  описывается изменением OpenSpec в репозитории сервера, потом кодом.
- В сообщениях коммитов — что и зачем. Без подписей помощников и машинных
  трейлеров: ни строк соавторства от инструментов, ни отметок сессий, ни
  приписок «сгенерировано».

## Соглашение участника (CLA)

Правки со стороны принимаются только после подписи соглашения участника —
текст в [`CLA.md`](CLA.md). Подпись ставится через CLA Assistant: бот
попросит её в первом PR, один раз на человека. Без подписи PR не сливается.
Правки владельца проекта CLA не требуют.

Зачем это нужно. Проект выходит под AGPL-3.0-only, и так будет для всех.
Кроме того, владелец оставляет за собой право продавать коммерческую
лицензию тем, кому AGPL не подходит. Чтобы предлагать её на весь код,
включая ваши правки, ему нужна лицензия на ваш вклад с правом
перелицензировать.

Что CLA **не** делает: права на ваш вклад не переходят владельцу, они
остаются у вас. Вы даёте бессрочную лицензию и можете использовать свой
код как угодно, в том числе в других проектах.
